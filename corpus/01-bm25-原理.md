# BM25 关键词检索原理

BM25 是一种经典的关键词检索打分算法，属于概率检索模型。它把查询拆成若干词项，对每个候选文档累计词项的匹配得分，最后按总分排序。BM25 的核心是两个统计量：词频 TF 和逆文档频率 IDF。

## 词频饱和与 k1 参数

词频 TF 表示某个词项在文档中出现了多少次。朴素的打分会让词频线性增长，但 BM25 做了饱和处理：一个词出现十次并不比出现一次重要十倍。公式中 k1 参数控制饱和的速度，k1 越大，饱和越慢，词频高的文档优势越明显；k1 越小，词频的影响越早趋于平缓。工程上 k1 通常取 1.2 到 2.0 之间，常见默认值是 1.5。

## 文档长度归一化与 b 参数

b 参数控制文档长度归一化的强度，取值范围是 0 到 1。b 等于 0 时完全不考虑文档长度，b 等于 1 时做完全归一化。默认值通常取 0.75，意思是长文档会被适度惩罚，避免长文档仅凭字数多就获得高分。归一化因子使用当前文档长度除以平均文档长度。

## IDF 与公式

逆文档频率 IDF 衡量一个词的区分能力。如果一个词在语料中几乎每篇文档都出现，它的区分度就低，IDF 接近零；如果一个词只出现在少数文档中，它的 IDF 就高。BM25 常用的 IDF 形式是 ln(1 + (N - df + 0.5) / (df + 0.5))，其中 N 是文档总数，df 是包含该词的文档数。

综合起来，一个查询词对文档的贡献等于 IDF 乘以饱和后的词频项 tf * (k1 + 1) / (tf + k1 * (1 - b + b * dl / avgdl))，其中 dl 是文档长度，avgdl 是平均文档长度。所有查询词的贡献相加就是 BM25 总分。

## 优缺点

BM25 的优点是不需要训练、可解释性强、对精确关键词匹配非常有效，而且计算开销小，适合作为检索系统的第一路召回。缺点是它不理解同义词和语义，查询词与文档用词不一致时就容易漏召回，因此常与向量检索组合成混合检索。
